Auto-discovery checks scheduled matches every 15 minutes and searches only allowlisted official channels.

LOW-LATENCY READY — Only channels explicitly allowlisted in Cloudflare can be auto-added. The Worker checks schedule windows, caps YouTube search usage at 70 search calls/day, and removes streams when the YouTube API no longer reports them live. Embedding may still be disabled by the broadcaster.
Security: Do not place private API keys in browser files. Use a server-side proxy such as Cloudflare Worker. Scores refresh every 30 seconds; source availability depends on the public provider.
